It's not all gold and glitter

Disadvantages

  • Setup right now is a bit tricky to get right (changes to Metro + Webpack)
    • But agents can usually handle it well!
  • React work on the main thread can be significant — careful optimizations and evaluation needed
  • The library hasn't reached stable yet — some perf improvements are still pending
  • It solves blank frames, but doesn't solve frame drops magically lol (no silver bullet)
    • It's a UI/UX decision at some point
